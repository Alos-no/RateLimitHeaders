Remarks

This handler should be registered as transient and used with IHttpClientFactory. Handler instances are pooled for approximately 2 minutes.

The handler parses RateLimit and RateLimit-Policy headers per the IETF specification (draft-ietf-httpapi-ratelimit-headers-10).
